# StyleNest — Fashion Store E-Commerce Product Interface

## Project Overview

StyleNest is a responsive fashion e-commerce website developed using HTML, CSS, and JavaScript. It allows users to explore fashion products, search for items, filter products by category and price, and add products to a shopping cart.

The project is designed with a clean and modern interface that works on desktop and mobile devices.

## Features

- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Product Display:** Displays fashion products with images, names, prices, and descriptions.
- **Search Functionality:** Search for products by name.
- **Category Filter:** Filter products by Clothing, Shoes, and Accessories.
- **Price Filter:** Display products within a selected maximum price.
- **Reset Filters:** Reset the search and filters to show all products.
- **Shopping Cart:** Add products to the cart and view selected items.
- **Quantity Management:** Increase or decrease product quantities.
- **Remove Products:** Remove products from the shopping cart.
- **Cart Count:** Display the number of items in the cart.
- **Local Storage:** Save cart items in the browser so they remain after refreshing the page.
- **Order Summary:** Calculate subtotal, shipping charges, and total price.
- **Free Shipping:** Offer free shipping when the subtotal reaches Rs. 5,000.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your web browser.
4. For a better development experience, run the project using the Live Server extension in VS Code.
5. Browse the products, use the search and filters, and add products to the shopping cart.
6. Open the cart page to manage quantities and view the order summary.

## How the Shopping Cart Works

The website uses JavaScript and browser Local Storage to manage shopping cart data. When a user adds a product, the cart is updated and saved in Local Storage. The cart data remains available after refreshing the page in the same browser.

## Important Note

This project is a front-end demonstration. It does not include a backend, database, real payment gateway, or actual order processing. The checkout button is for demonstration purposes only.
